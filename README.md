# Frontier War

A single-player, offline, sandbox RTS for Android, made in Unity by one developer.
**Gameplay** is inspired by *Rusted Warfare* and the **look** by *Ebbtide*. Everything in the game itself is original.

## Folder structure
```
RTS/
  README.md                     ← you are here
  Docs/
    00_Index.md                 ← start here: what to read and in which order
    01_Research/                ← studies of Rusted Warfare (mechanics) and Ebbtide (look)
    02_GameDesign/              ← the illustrated GDD (PDF + HTML source)
    03_TechnicalDesign/         ← how every system works, for Unity (00 to 12)
    04_Production/              ← roadmap, rules, task board, trackers, setup guide
    _Archive/                   ← old drafts (don't use)
  Art/
    Concepts/                   ← locked look images (pixel, clean, style tests)
    Tools/                      ← export settings, palette
    _Archive/                   ← rejected art directions
  Unity/                        ← the Unity project goes here (created in milestone M0)
```
